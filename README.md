# 🔊 Text-to-Speech System

A simple desktop Text-to-Speech (TTS) application developed in Python using Tkinter. The application allows users to convert text into speech, save speech as an MP3 file, and play saved audio.

## Features

- Convert text to speech
- Male/Female voice selection (system-dependent)
- Adjustable speech speed
- Save speech as MP3
- Play saved MP3 files
- Multiple language support (English, Hindi, Bengali, French, Spanish)
- User-friendly Tkinter GUI

## Technologies Used

- Python
- Tkinter
- pyttsx3
- gTTS
- pygame

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Text-to-Speech-System.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
